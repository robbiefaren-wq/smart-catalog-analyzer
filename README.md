# Smart Catalog Analyzer 🛒

## About
A console-based educational project written in vanilla JavaScript for processing product catalogs. It is implemented using functional programming principles.

## ✨ Features

- **Category Filtering** - Search for in-stock products by category and minimum rating.
- **Catalog Sorting** - Search for in-stock items. By catalog.
- **Warehouse Analytics** - Calculation of the cost of warehouse goods.
- **Group / Grouping** - Grouping product names by category.

## 👩‍💻 Tech Stack 

- JavaScript
- functions
- filter method
- map method
- sort method
- reduce method
